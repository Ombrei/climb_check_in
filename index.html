Settings & Install

Customize your default Mon–Sun schedule. You can assign multiple Climbing Gym days per week and still override any single day anytime.

Host this single HTML file anywhere over HTTPS (GitHub Pages, Netlify, or Vercel) and install it permanently—it never expires like free Xcode builds.

Add to Home Screen (iOS Safari):

  1. Open your hosted link in Safari on iPhone.
  2. Tap the Share icon (square with upward arrow).
  3. Scroll down and tap Add to Home Screen.
  4. Launch from the new icon for full-screen standalone mode.

ADHD Check-In Nudge Tip:

In the iOS Shortcuts app, create two daily Personal Automations (e.g., 9:00 AM & 6:30 PM) with the action Open URL pointing to your hosted page.
